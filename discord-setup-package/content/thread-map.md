# The Map On The Wall

The Threads are how the whole project connects.

A thread is not just a topic. It is a recurring wire running through the book, the documentary, the archive, the Discord, the room map, and the Trap Pass.

Origin:
- January 22 / The Origin / Blast Crater

Main wires:
- Addiction Machine
- Psychosis Loop
- Grief / Loss
- Cats / Home / Tenderness
- Writing Inside The Fire
- Money Desperation
- System Mirror
- Platform War
- Trap Pass Lore
- Self-Destruction vs Creation
- Public Project / Witness
- Ending Convergence

The flow:
January 22 fractures everything. Grief feeds addiction. Addiction feeds money desperation and psychosis loops. Cats and home push back against collapse. Writing turns collapse into evidence. The system mirror turns private pain into social critique. Platform war forces migration. Trap Passes make the audience participants. Public witness pulls everyone inside. In the end, all threads converge.
